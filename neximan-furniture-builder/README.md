# Neximan Furniture Builder

افزونه‌ی مستقل وردپرس/المنتور برای ساخت محصولات قابل پیکربندی (مبل، میز، تخت و ...) با
قیمت‌گذاری داینامیک و اتصال به سبد خرید و تسویه‌حساب ووکامرس.

این افزونه نسخه‌ی مستقل و توسعه‌یافته‌ی ویجت `mobl build` است که قبلاً برای افزونه
«Unlimited Elementor» ساخته شده بود؛ حالا دیگر به هیچ افزونه‌ی واسطی وابسته نیست.

## امکانات

- **ویجت مستقل المنتور** در دسته‌بندی «Neximan» (نیازی به Unlimited Elementor نیست).
- **ماژول/محصول چندگانه**: با یک repeater می‌توانید چند محصول (مثلاً مبل، میز، تخت) با
  تب جداگانه تعریف کنید. هر ماژول نوع، قیمت پایه و تصاویر خودش را دارد.
- **چیدمان‌های قابل تعریف**: لیست چیدمان‌ها (۲ نفره، ۳ نفره، L و ...) را خودتان می‌سازید.
  هر چیدمان به یک «اسلات تصویر» (۱ تا ۸) وصل می‌شود.
- **قیمت داینامیک**: قیمت نهایی = قیمت پایه‌ی ماژول + افزایش قیمت چیدمان + افزایش قیمت رنگ.
  قیمت به‌صورت زنده در پنل نمایش داده می‌شود.
- **اتصال ووکامرس**:
  - افزودن به سبد خرید با AJAX (بدون رفرش صفحه).
  - حالت «افزودن و رفتن به تسویه‌حساب» (خرید سریع / فاکتور).
  - ذخیره‌ی ترکیب انتخابی (مدل/چیدمان/رنگ) روی آیتم سبد و سفارش.
  - دو حالت قیمت: «داینامیک» (قیمت ساخته‌شده در ویجت) یا «قیمت محصول ووکامرس».
  - محاسبه‌ی قیمت **در سمت سرور** انجام می‌شود تا از دستکاری قیمت جلوگیری شود.
- **پیش‌نمایش رنگ پارچه** با تکنیک CSS mask (تغییر رنگ روی تصویر مبل).
- **استایل قابل تنظیم** از تب Style المنتور (رنگ اکسنت، رنگ تیره، پس‌زمینه‌ی پیش‌نمایش، تایپوگرافی).

## نصب

1. پوشه‌ی `neximan-furniture-builder` را به `wp-content/plugins/` کپی کنید
   (یا آن را zip کرده و از مسیر «افزونه‌ها → افزودن → بارگذاری افزونه» نصب کنید).
2. افزونه را فعال کنید. (المنتور باید نصب و فعال باشد؛ برای امکانات سبد خرید، ووکامرس هم.)
3. در ویرایشگر المنتور، ویجت **Furniture Builder** را از دسته‌ی **Neximan** به صفحه بکشید.

## نحوه‌ی استفاده

1. **General**: عنوان، زیرعنوان، متن دکمه، واحد پول و تنظیمات نمایش قیمت.
2. **Layout Options**: چیدمان‌ها را تعریف کنید. هر ردیف:
   - برچسب (مثلاً «۳ نفره»)
   - شماره‌ی اسلات تصویر (۱ تا ۸)
   - افزایش قیمت برای این چیدمان
3. **Modules / Products**: محصولات را اضافه کنید. هر ردیف:
   - نام ماژول (متن تب)
   - نوع (مبل/میز/تخت/سفارشی)
   - قیمت پایه
   - شناسه‌ی محصول ووکامرس (اختیاری)
   - تصویر برای هر اسلات چیدمان (Slot 1 تا Slot 8)
   > دکمه‌ی چیدمانی که این ماژول برای آن تصویری ندارد، به‌صورت خودکار پنهان می‌شود؛
   > بنابراین یک «میز» می‌تواند چیدمان‌های متفاوتی نسبت به «مبل» نمایش دهد.
4. **Fabric Colors**: رنگ‌های پارچه با نام و افزایش قیمت اختیاری.
5. **WooCommerce**: عملکرد دکمه، حالت قیمت و شناسه‌ی محصول پیش‌فرض (fallback).

### نکته درباره‌ی قیمت داینامیک و ووکامرس

برای افزودن به سبد، ووکامرس به یک «محصول» نیاز دارد. دو راه دارید:

- **هر ماژول → یک محصول ووکامرس** (فیلد `WooCommerce Product ID`).
- یا یک **محصول پیش‌فرض (Fallback Product)** بسازید (مثلاً یک محصول ساده‌ی مخفی) و در
  حالت قیمت «داینامیک»، قیمت ساخته‌شده در ویجت روی همان خط سبد اعمال می‌شود.

## ساختار فایل‌ها

```
neximan-furniture-builder/
├── neximan-furniture-builder.php      # فایل اصلی افزونه + بررسی پیش‌نیازها
├── includes/
│   ├── class-neximan-builder.php      # راه‌انداز، ثبت دسته/ویجت/اسکریپت‌ها
│   └── class-neximan-woocommerce.php  # AJAX، قیمت داینامیک، متای سبد/سفارش
├── widgets/
│   └── class-neximan-builder-widget.php   # ویجت و کنترل‌های المنتور
└── assets/
    ├── css/builder.css
    └── js/builder.js
```

## نقشه‌ی راه (مرحله‌ی بعد)

- پنل تنظیمات سراسری/Custom Post Type برای محصولات با تعداد نامحدود چیدمان و تصاویر.
- آپلودر تصویر داخل ردیف چیدمان (به‌جای سیستم اسلات ثابت).
- پشتیبانی از متغیرهای ووکامرس (variation) به‌جای محصول ساده.
- ساخت فاکتور/پیش‌فاکتور مستقل از سبد خرید.
